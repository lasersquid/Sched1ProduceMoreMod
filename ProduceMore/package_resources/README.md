# ProduceMore

Tired of waiting 8 hours for lab ovens? Configure station speed, employee work animation speed, walk speed, stack limits, and more.

This mod is for anyone who wants to accelerate their production. Or if you like a more leisurely playthrough, you can also slow things down.


## Features

 - Modify station operating speed
 - Modify batch size of mixing station, drying rack, packaging station
 - Modify mixing station threshold up to the batch size
 - Modify stack sizes by category, with optional overrides for individual items. This includes cash!
 - Modify employee work animation speed by station (hanging leaves on drying rack, etc)
 - Modify employee walk speed


## Configuration

The default mod configuration is to match unaltered game settings. To see the effects, modify the configuration using a mod management app like ModsApp by k0, or modify the config file by hand at Schedule I/UserData/ProduceMore.cfg using any text editor (eg, Notepad).

Setting employee walk speed too high may result in pathfinding issues. If your employees have trouble navigating tight spaces, consider turning down the multiplier.
